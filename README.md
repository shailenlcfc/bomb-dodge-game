# Bomb Dodge (browser game)

A small arcade game built in HTML, CSS and JavaScript during my first year of BSc Computing at the University of Northampton (Web Development module, 2021).

**Play it:** open `index.html` in a browser, or use the GitHub Pages link for this repo.

## How it works
- Move the player with the arrow keys and dodge the falling bombs
- Health bar, explosions, and start and game-over screens
- Sprite-based animation driven by JavaScript

## Credit
Built on the course's starter framework for player movement and sprites, which I extended for the assignment.
